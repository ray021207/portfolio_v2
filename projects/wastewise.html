The problem with a single 'recyclable' label

The same object can require different disposal decisions across municipalities. A greasy pizza box and a clean cardboard box may need different treatment even if they look similar to a basic image classifier.

WasteWise was designed to accept a photo and produce a reasoned, location-aware suggestion rather than a fixed class label.

A visual reasoning pipeline

The app uses Claude's visual understanding to identify an item and reason about disposal edge cases. Its project README describes camera/upload input, local-rule logic, special-item drop-off guidance and a Streamlit interface.

FiftyOne is part of the data-inspection story, storing and reviewing visual samples so failure cases could become a learning resource. That design connects a quick prototype with an evaluable visual-AI workflow.

What the demo does not prove

The README documents intended city-aware guidance, gamified impact estimates and analysis surfaces. It does not establish certified compliance with every municipal rule or that every impact estimate has been independently audited.

For a deployment, I would prioritize official rule provenance, uncertainty flags and a human-check option for hazardous or ambiguous items.

What this evidence supports

Hackathon project. The repository describes product features and prototypes, not a validated municipal recycling authority.
