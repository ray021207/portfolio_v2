The real workflow

Fruit grading requires consistent visual assessment of surface condition and quality. Manual inspection varies by operator, and a useful technical system has to put the prediction into a repeatable workflow.

The undergraduate project combined image-based CNN analysis with a web application for receiving photographs, reporting grades and recording results.

What was built

The project explored transfer-learning approaches including ResNet50 and InceptionV3. A Flask-backed application with HTML, CSS and JavaScript provided an interface, while MySQL supported persistence and a grading log.

The point was not just model choice: the interface and stored records made the system usable as an application rather than an isolated trained notebook.

Publication and boundaries

The work was published as 'Computer Vision Based Fruit Grading System Using Machine Learning Techniques' in IOSR Journal of Computer Engineering, volume 26, issue 3 (2024). The source repository documents the implemented stack and intended grading workflow.

The public summary does not provide a verified external production deployment, multi-site validation, or a transferable accuracy guarantee. Those should not be inferred from the publication alone.

What this evidence supports

Publication and implementation claims are drawn from the existing project record; production-scale field validation is not claimed.
