What does it mean to know enough?

Imagine a robot entering a home it's never seen. Someone asks whether the kettle is on the counter. The robot must look around, remember what it has observed, judge which places are relevant, and finally decide when it's ready to answer.

GraphEQA introduces a spatial memory layer—a scene graph—that helps a vision-language planner reason about its surroundings. Our replication exposed an uncomfortable pattern: the agent sometimes ended its search and answered confidently while wrong.

Getting the experiment to run was an experiment

I first worked through the software stack on ASU's Sol supercomputer: containers, scheduling, GPU compatibility and dependencies across robotics, mapping and vision. This setup work mattered because reproducible evaluation requires more than a model checkpoint.

The relevance signal was the weak link

The original relevance calculation depended on batch-relative similarities. That means the apparent relevance of the same observation could change depending on what else was being compared. I worked on a SigLIP2-based signal and a compact learned relevance head so navigation decisions could be less dependent on that accident of scoring.

One revealing ablation was label provenance. A model that fit its labels more cleanly did not necessarily drive the downstream planner better. The weaker training curve sometimes produced better navigation behavior because its supervision aligned more closely with the model using it.

Better behavior doesn't always mean a higher accuracy number

Some changes reduced confident wrong answers without immediately raising overall answer accuracy. The agent was no longer quitting too early; it was now staying in the environment longer and struggling to find confirming evidence. That's an improvement in failure mode even when the headline score barely moves.

Scope: These are results from the reported episode subsets and ablations, not a claim of fully deployed autonomous operation in the physical world. The exact evaluations and comparisons are documented in the original work.

What I'd work on next

  • Calibrate confidence separately for question types instead of sharing one threshold.
  • Check relevance scores for stability across environments and observation batches.
  • Distinguish “I searched but didn't find it” from “I'm sure it isn't there.”
  • Evaluate with longer trajectories and a larger, geographically varied set of unseen scenes.
